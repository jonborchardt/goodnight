# goodnight

Single-page React 19 + TypeScript app built with Vite and [MUI](https://mui.com/).

Deployed to GitHub Pages on every push to `main` (served under `/goodnight/`).

## Development

```sh
npm install
npm run dev      # dev server with HMR
npm run build    # type-check + production build
npm run lint     # oxlint
npm run preview  # serve the production build locally
```
